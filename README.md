# Personal Portfolio Website

## Project Overview

This is a full-stack personal portfolio website created to showcase my skills, projects, and contact details. The project includes frontend development, backend integration, database connectivity, and deployment.

The website is responsive and works on both desktop and mobile devices.

---

# Technologies Used

## Frontend
- HTML
- CSS
- JavaScript

## Backend
- Node.js
- Express.js

## Database
- MongoDB

## Deployment
- Netlify / Vercel

---

# Features

- Home page
- About section
- Skills section
- Projects section
- Contact form
- Responsive design
- Backend integration
- Database support
